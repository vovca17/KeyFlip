# KeyFlip

Нативная утилита для macOS 13+, Swift + AppKit, без зависимостей и сетевых запросов.

## Сборка и запуск

Нужны macOS 13+, Xcode / Command Line Tools с поддержкой Swift 6 и Python 3.

Для подписанного `.app` скопируй `scripts/signing.example.sh` в `scripts/signing.local.sh` и укажи свой сертификат Apple и Team ID. Локальный файл подписи игнорируется Git. Для разработки ядро и исполняемый файл собираются без сертификата через `swift build --disable-sandbox`; тесты — командой из раздела «Проверка».


```sh
bash scripts/build.sh
open "build/.releases.noindex/KeyFlip.app"
```

Разреши **KeyFlip** в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. Если система запросит мониторинг ввода, разреши его. В меню **⇄** выбери «Разрешения / подключить заново…» или перезапусти приложение. Отключи Punto Switcher во время проверки, чтобы две утилиты не исправляли один текст одновременно.

Включи источники ввода **ABC** или **US** и **Русская** (либо **Русская — ПК**). Преобразование рассчитано на стандартную раскладку ЙЦУКЕН; фонетические раскладки не поддерживаются.

## Использование

- **⌥Space** меняет раскладку выделения, а без выделения — последнего слова перед курсором. Повторное нажатие конвертирует слово обратно.
- **Автоисправление** проверяет слово после пробела. Например, `ghbdtn ` → `привет `, если доступны системные словари RU и EN и исходное слово не признано правильным.
- Автоматика проверяет слова от 4 до 40 символов по системным словарям и короткие слова (1–3 буквы) по встроенному списку, набранные при запущенной утилите. Если сразу продолжить печатать после пробела, проверка не отменяется: KeyFlip находит слово с учётом уже набранного после него текста. Клик, стрелки, Enter, Tab и смена приложения отменяют проверку.
- Меню **⇄**: автоисправление, пауза, исключение активного приложения. Исключения отключают и автоматическое исправление, и горячую клавишу. Terminal и iTerm2 исключены по умолчанию.
- Автопереключение источника ввода выполняется после успешной замены. Утилита не ведёт журнал, не сохраняет введённый текст и не использует буфер обмена.

## Ограничения первой версии

Исправление требует, чтобы поле предоставляло текст и управление выделением через Accessibility. Если прямая замена AXSelectedText недоступна, используется ввод Unicode клавиатурным событием после проверки выделенного диапазона. После любой замены KeyFlip перечитывает поле; если текст не изменился, причина пишется в «О программе → Диагностика», а возврат этого исправления отключается, чтобы не задеть чужой текст. Причина последней попытки автоисправления отображается в диагностике окна настроек. Неподдерживаемые поля пропускаются; при ручной команде звучит сигнал. Для терминалов, редакторов с собственными текстовыми поверхностями и отдельных браузерных полей совместимость нужно проверять отдельно. Защищённый ввод и поля паролей пропускаются.

Распознавание намеренно осторожное: неоднозначные слова, идентификаторы и смешанные алфавиты обычно пропускаются. Частые короткие слова проверяются по встроенному списку. Если в macOS недоступен один из словарей, автоисправление пропускает соответствующие слова; ручная команда продолжает работать. Системный словарь не гарантирует правильное определение намерения автора. Это MVP, а не проверенная замена Punto во всех приложениях.

Проект находится в разработке. Текущие сборки не нотарифицированы; готовые публичные релизы пока не опубликованы. Автозапуск доступен в настройках.

## Проверка

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift test --disable-sandbox
```

После выдачи разрешений проверь в TextEdit: ручное `ghbdtn` → `привет`, выделенную фразу, повторную конвертацию, автоисправление после пробела, паузу, исключения и сохранение текста с эмодзи. Совместимость с другими приложениями требует ручной проверки.

## Почта в неверной раскладке

После пробела `мдфвшьшкюыфнфзшту"пьфшдюсщь` исправляется в `vladimir.sayapine@gmail.com`. Кавычка считается предполагаемой @ только если весь результат похож на обычный ASCII email с доменом и зоной. Проверки существования адреса нет. Правильно набранные английские адреса не меняются. Для email допускаются цифры и длина до 254 символов; словарь для адресов не нужен.

## Имена

Встроен небольшой справочник русских и латинских написаний: `мдфвшьшк` → `vladimir`, `dkflbvbh` → `владимир`. Регистр сохраняется. Имена проверяются после пробела, даже если исправленный вариант отсутствует в системном словаре; известное системному словарю исходное слово не меняется. Через меню **⇄ → Свои имена…** можно добавить свои написания, например имя и фамилию, раздельными словами. Они сохраняются локально между запусками. Это исправление раскладки; транслитерация и распознавание всех возможных имён не выполняются.

## Правый Option и возврат исправления

Нажми и отпусти правый Option без других клавиш: последнее слово или выделение меняет раскладку. Повторное нажатие возвращает точный исходный текст. Сразу после автоматического исправления эта же клавиша отменяет его, в том числе восстанавливает кавычку в ошибочно исправленной почте. Пробел после слова сохраняется. ⌥Space также поддерживается. Левый Option и сочетания правого Option с клавишами не вызывают исправление.

Для возврата в памяти хранится только последнее исправление; обычный ввод сбрасывает его. Перед возвратом сверяются поле, позиция курсора и исправленный фрагмент. Команда действует на текущий текст у курсора, а не является общей историей отмены редактора.

## Установка, автозапуск и локальные обновления (0.2.0)

Готовый установщик: `build/KeyFlip.dmg`. Перетащи KeyFlip в Applications или используй «Установить в Программы…» при запуске из папки сборки. Постоянный путь — `/Applications/KeyFlip.app`. Не запускай параллельно старые копии из build.

В меню ⇄ есть «Запускать при входе» (SMAppService) и «Установить локальное обновление…». После изменения исходников выполни `bash scripts/build.sh`: увеличится номер сборки, установленное приложение сможет обновиться одной командой меню и перезапустится. Сетевой сервер не нужен; путь к локальной сборке записан в подписанный Info.plist. Папку проекта нужно сохранить на этом Mac. Удаление проекта не мешает работе установленной версии, но убирает источник обновлений.

Сборки подписываются имеющимся Apple Development сертификатом, без ad-hoc подписи. При смене подписи со старых версий Accessibility / Input Monitoring может потребоваться выдать заново один раз. Для будущих сборок используй тот же сертификат и bundle identifier. Для другого сертификата укажи KS_SIGN_IDENTITY и KS_SIGN_TEAM в локальном файле scripts/signing.local.sh; требование подписи обновлений формируется из этих настроек.

Установщик проверяет подпись до и после копирования, готовит новую копию рядом с установленной, затем заменяет приложение. При ошибке замены восстанавливает предыдущую копию. Предыдущая версия сохраняется в `~/Library/Application Support/KeyboardSwitcher/Previous.zip`; журнал — `~/Library/Logs/KeyboardSwitcher/update.log`. При аварийном отключении питания или сбое самого запуска автоматический откат не гарантируется.

Создать новый DMG после сборки: `bash scripts/package.sh`. DMG и установленная версия проверены локально. Сборка предназначена для этого Mac с Apple Silicon, не нотарифицирована и пока не подготовлена для распространения друзьям.

Логотип: `assets/keyflip.svg` (вектор), `assets/keyflip.png` (1024×1024), иконка приложения генерируется `scripts/make-icon.swift`.

## Настройки 0.3.0

Основное меню содержит действия без счётчиков и технических статусов. Версия, подключение клавиатуры, Secure Input, словари и причина последней проверки доступны в **О программе → Диагностика**; там же можно подключиться заново.

**Исключённые приложения** показывает открытые обычные приложения и сохранённые исключения, включая закрытые. Галочка отключает и автоматическое, и ручное исправление. Список открытых приложений обновляется при открытии меню.

**Клавиша исправления** позволяет выбрать левый/правый Option, Command или Control, ⌥Space либо записать своё сочетание с Command/Option/Control и дополнительным Shift. Для одиночной клавиши срабатывает нажатие с отпусканием без других клавиш. Выбор сохраняется. Прежнее ⌥Space доступно как отдельный вариант.

**Исключения слов…** — редактируемый локальный список, одно слово или адрес на строку, без учёта регистра. Исключения блокируют только автоматику; ручная команда работает. После трёх отмен автоматической замены одного исходного слова за сеанс появляется предложение возле значка KeyFlip: добавить слово или отложить. Предложение показывается один раз для слова за сеанс, добавление выполняется только по нажатию пользователя. История этих отмен ограничена и не сохраняется как журнал ввода.

## Chromium и Electron (0.3.2)

В Chrome-подобных браузерах и Electron-приложениях (bb, Slack, Discord, VS Code и др.) поле принимает прямую запись Accessibility, но скрипт страницы возвращает старый текст. Там KeyFlip заменяет слово вводом Unicode-событий клавиатуры, как при обычном наборе, без буфера обмена. В остальных приложениях, если после прямой записи в поле осталось исходное слово, выполняется одна повторная попытка через ввод. Способ и результат последней замены показаны в «О программе → Диагностика».

`KeyboardSwitcher --probe <файл>` записывает возможности активного поля (роль, доступные для записи атрибуты) без его текста.

## Короткие слова, Caps Lock, фразы и раскладка приложений (0.4.0)

- **Короткие слова.** Встроенный список частых слов до 3 букв (`ShortWords.swift`): «я», «и», «в», «не», «на», «как», «что», «это», «the», «and», «you» и т. д. Слова из 2–3 букв исправляются сразу: `rfr ` → `как `. Однобуквенные («я», «и», «в», «к», «с», «у», «о», «а») исправляются только вместе со следующим словом в той же раскладке: `z nen ` → `я тут `. Не исправляются автоматически слова, совпадающие с аббревиатурами другого языка: «мы» (vs), «во» (dj), «in» (шт).
- **Caps Lock.** `пРИВЕТ ` → `Привет `, `gHBDTN ` → `Привет `, если исправленное слово есть в словаре. После такого исправления Caps Lock выключается.
- **Фраза целиком.** Клавиша исправления без выделения меняет последнее слово и предыдущие слова той же строки, которые выглядят набранными в неверной раскладке: `z ns ult` → `я ты где`. Правильные слова останавливают расширение. Повторное нажатие возвращает всю фразу.
- **Раскладка для каждого приложения.** KeyFlip запоминает последнюю раскладку в каждой программе и включает её при переключении. Отключается в меню ⇄. Для исключённых приложений не действует. Хранятся только идентификаторы приложений и раскладок.

## Окно настроек (0.5.0)

Меню ⇄ → **Настройки…** (⌘,) открывает окно с вкладками:

- **Основные** — автоисправление, раскладка для каждого приложения, автозапуск, клавиша исправления (список или «Записать своё…»).
- **Исключения** — приложения с иконками (+ из запущенных или «Другое приложение…», − удалить) и слова без автоисправления.
- **Имена** — свои имена и фамилии; сохраняются сразу, ошибки подсвечиваются.
- **О программе** — версия, обновление, переподключение и диагностика.

В самом меню остались быстрые действия: автоисправление, пауза, «Выключить в «приложение»» для активной программы, настройки, обновление, выход. Пункты меню из разделов выше в старых версиях заменены этим окном.

`KeyboardSwitcher --render-settings <папка>` сохраняет вкладки окна в PNG для проверки внешнего вида.
